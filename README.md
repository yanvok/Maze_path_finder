# Maze_path_finder

This project implements five separate programs, each utilizing a different pathfinding algorithm to solve the problem of navigating a maze from a start point to an end point.

Implemented Algorithms:
  1) Random Search
  2) Depth-First Search (DFS)
  3) Breadth-First Search (BFS)
  4) Greedy Best-First Search
  5) A* (A-Star) algorithm with such a heuristic that it always finds the shortest path.
